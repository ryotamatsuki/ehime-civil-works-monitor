# Data Sources

一次資料を優先します。原則として、事業主体の個別事業・事業評価資料 → 予算資料 → 公式Webページ → 市町等の関連公式資料の順で確認します。

Phase 1の主要ソースは愛媛県「令和7年度愛媛県公共事業評価委員会」です。

- https://www.pref.ehime.jp/page/127397.html
- https://www.pref.ehime.jp/uploaded/attachment/162763.pdf

各sourceは `id`, `title`, `publisher`, `url`, `accessed` を保持します。検索結果の要約だけで重要な数値を登録しません。
