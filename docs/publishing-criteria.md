# 掲載基準・データについて

Ehime Civil Works Monitor は、愛媛県内の公共土木事業を公式資料から整理する非公式モニターです。

## 掲載対象の定義

本サイトでは、愛媛県内で実施中または具体的に計画されている公共土木事業のうち、国・愛媛県等の公式資料から、独立した事業として名称・事業主体・実施地域を確認できるものを掲載対象とします。

掲載件数は、愛媛県が公式に選定した「重点事業」の件数ではありません。また、愛媛県内で実施されている公共土木事業の全件数を示すものでもありません。

公式資料を横断して事業単位を確認できた案件を順次canonical inventoryへ追加します。

## 掲載する事業

道路、河川、砂防、港湾、海岸、都市、ダム等について、公式資料上で政策・予算・事業評価等の単位として独立したProjectであることを確認できる事業を収録します。

愛媛県施行事業に限らず、愛媛県内で実施される国直轄等の公共土木事業も、事業主体を明示したうえで対象とします。

## 最低掲載条件

canonical Projectへ追加するためには、原則として次を確認します。

1. 公式一次資料で独立した事業名を確認できること
2. 事業主体または所管を確認できること
3. 実施市町・地域を合理的に特定できること
4. 既存Projectとの重複確認が完了していること
5. 上位Projectに属する単一工区・工事・業務ではないことを確認できること
6. 根拠となるprimary sourceが存在すること

総事業費、完成年度、進捗率、B/C、年度予算等の数値は掲載の必須条件ではありません。確認できない値は推測せず `null` または空データとして扱い、0とはみなしません。

## 主な確認資料

候補探索・identity reconciliationには主として次の公式資料群を使用します。

- 「えひめの土木」
- 愛媛県「道路の整備に関するプログラム」
- 愛媛県公共事業評価資料
- 愛媛県当初・補正予算資料
- 地方局・土木事務所の主要事業・事業紹介
- 国土交通省・四国地方整備局資料
- 発注見通し

発注見通しは事業候補の探索には利用しますが、個別の工事・委託契約1件をそのままcanonical Projectとはしません。

## 原則として掲載しないもの

次は、それだけではcanonical Projectとして掲載しません。

- 単一の工事契約
- 測量・設計等の単一委託業務
- 独立事業であることを確認できない単なる施設名
- 独立事業scopeを確認できない路線名・河川名・港湾名
- 民間事業
- 県事業・国事業との関係がない市町単独事業
- 公式資料で事業identityを確認できない案件

大規模更新、耐震化、長寿命化等については、公式資料上で独立事業として管理されている場合は対象にできます。

## Project / Work Package / Asset

本サイトは次を区別します。

- **Project**: 政策・予算・事業評価上の独立した公共事業。canonical inventoryの基本単位。
- **Work Package**: Projectを構成する工区、橋梁工、トンネル工、改良工、用地補償、測量設計等。
- **Asset**: 橋、トンネル、港、ダム等の施設そのもの。

Work PackageやAssetを、独立Projectである根拠なしに別Projectとして水増ししません。

## 網羅性

本サイトは公式資料から確認できた案件を体系的に追加していますが、県内公共土木事業の完全な全件データベースではありません。

資料公開の粒度が粗く、上位Projectを確認できない工区・路線・河川等は保留します。新たな一次資料でidentityを確認できた場合は追加・reconcileします。

## 位置情報

公式GIS geometryを確認できた場合はそれを優先します。確認できない場合は、公式資料に記載された市町・地区等から検索・俯瞰用の代表点または概略geometryを作成します。

`locationAccuracy: approximate` の位置は、正確な施工区域、道路線形、河川改修区間、砂防施設位置等を示すものではありません。

## 数値データ

総事業費、事業期間、進捗、B/C、年度予算等は一次資料で確認できた値だけを収録します。定義やscopeが異なる値は自動的に合算・比較しません。

詳細なデータポリシーは `README.md`、`docs/data-schema.md`、`docs/comprehensive-project-inventory-audit.md`、`docs/annual-budget-reconstruction.md` を参照してください。
