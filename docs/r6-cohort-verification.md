# FY2024 Cohort Verification

The FY2024 (令和6年度) evaluation cohort expansion is verified as a cohort-level data update.

## Coverage

- 13 FY2024 re-evaluation projects represented, including the Matsuyama City delegated project
- 23 canonical project records in the full dataset
- 23 GeoJSON features
- 23 Phase 2.1 enrichment records
- 6 projects with multi-period B/C observations
- 11 projects with source-documented cost, schedule, or delay reasons

## Data discipline

- Unknown values remain `null` or empty histories.
- Project-level and network-level B/C are not mixed.
- Planned fiscal-year-end cumulative investment is not presented as actual expenditure.
- A narrative delay reason alone does not create a machine-derived `DELAYED` event.
- Approximate map points are navigation aids, not official construction footprints.
